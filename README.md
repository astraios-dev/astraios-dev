# React Website Template

Empty React single-page website template.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates the production bundle and publishes it to the site root for static hosting.
- `npm run preview` serves the production bundle locally.

Editable React source lives in `app/`. The root `index.html` and `assets/`
files are generated by the production build so the Caddy-served site root can
serve the React app directly.
